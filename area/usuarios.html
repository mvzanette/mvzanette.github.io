O que cada perfil acessa

MóduloAdministradorPessoalCliente

Regras

  • Os módulos profissionais (ART, controle financeiro e demandas da engenharia) mostram os mesmos dados para todos que têm permissão: não existe uma cópia separada por pessoa.
  • Cliente nunca acessa os módulos profissionais, mesmo que estejam marcados: o banco de dados bloqueia.
  • Finanças pessoais (gastos e investimentos) é separado do controle financeiro da engenharia: cada pessoa vê só o próprio painel, importado do projeto Financeiro. Os dados ficam no banco, protegidos pelo login, e nunca no código do site.
  • Cadastro marcado como inativo perde o acesso na hora, inclusive se estiver com a área aberta.
  • Sempre fica pelo menos um administrador ativo.

Como cadastrar alguém

  1. Aqui, em Novo usuário: nome, e-mail, perfil e módulos.
  2. No Supabase, em Authentication → Users → Add user → Create new user: o mesmo e-mail, uma senha provisória e Auto Confirm User marcado.
  3. Envie para a pessoa o endereço da área, o e-mail e a senha provisória. No primeiro acesso, ela troca a senha em Minha conta.
